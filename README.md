# AquaTrack

* **Nombre del proyecto:** AquaTrack
* **Integrante:** Leandro Aparicio

## Fundamentación
El sistema surge para resolver la necesidad de un control y monitoreo eficiente de recursos hídricos. Permite centralizar el registro de datos, facilitando la visualización de métricas de consumo y el control operativo a través de una plataforma web accesible.

## Objetivos
* **Objetivo General:** Desarrollar una aplicación web para la gestión, monitoreo y control en tiempo real de los datos relacionados con recursos hídricos.
* **Objetivos Específicos:**
  * Proveer un panel de control interactivo para visualizar métricas clave.
  * Automatizar el registro de datos y el historial de consultas.
  * Facilitar la administración de usuarios y dispositivos o fuentes de medición.

## Marco Teórico
* **Arquitectura Web:** Modelo cliente-servidor para la comunicación fluida entre la interfaz de usuario y la base de datos.
* **Gestión de Proyectos:** Metodologías ágiles (Scrum) utilizando tableros Kanban en GitHub para el control de tareas y control de versiones.
* **Diseño UI/UX:** Enfoque en la usabilidad, accesibilidad y claridad visual para la toma de decisiones.
